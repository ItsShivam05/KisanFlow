# KisanFlow 🌾

AI-powered farm-to-market supply network.

## Problem

Multiple intermediaries reduce farmer earnings
and increase consumer prices.

## Solution

KisanFlow connects farmers/FPOs directly with
consumers and bulk buyers while providing:

- Demand forecasting
- Price intelligence
- Supply matching
- Order aggregation
- Route optimization
- Wastage reduction

## Tech Stack

### Frontend
Next.js + TypeScript + Tailwind CSS

### Backend
Node.js + Express

### Database
PostgreSQL + PostGIS

### AI/ML
Python + FastAPI

### Optimization
